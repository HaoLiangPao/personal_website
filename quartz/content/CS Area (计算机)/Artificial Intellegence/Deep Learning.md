## Type of Deep Learning

Here's a visual "family tree" of deep learning architectures:

- **DNN (Deep Neural Network)** is the root.
- From DNN, we branch into:
    - **FNN** (basic feedforward networks)
    - **CNN** (for images)
    - **RNN** (for sequences), which leads to:
        - **LSTM** and **GRU** (variants handling long-term memory)
    - **Transformer**, which gave rise to:
        - **BERT**, **GPT**, **T5**, **ViT (Vision Transformer)**, and **ChatGPT**
