### Memory

| Level | Model | Type |     |
| ----- | ----- | ---- | --- |
|       | 3600  | DDR4 |     |
|       |       | DDR5 |     |


1. DDR4 is the old version, not recommended at all.
2. 内存最重要的属性是 **颗粒**
	1. DDR5
		1. 海力士 A代 （最好的）
		2. 海力士 M代
3. 内存 **时序**
	1. 时序越低，延迟越低，性能越好，但是更不稳定，电压和主板可能不一定支持
	2. 如: c28，c30，c32，c36
4. 内存 **频率**
	1. 如：6000，6200，6400，6800，8000
5. 不同厂商生产的同样的频率的内存可能出现差异

一般推荐：
- 32G 
- 6000 + c28 (就差不多了)
