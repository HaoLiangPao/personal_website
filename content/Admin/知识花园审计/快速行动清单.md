每次发布新文章，检查：

```markdown
发布前检查清单:

内容质量:
- [ ] 字数 ≥ 200 词 (短定义除外)
- [ ] 至少 1 张图表或代码示例
- [ ] 清晰的结构（标题、段落分明）

元数据:
- [ ] 有完整的 frontmatter
- [ ] 有 3+ 个相关的标签
- [ ] draft: false (准备发布)

链接与网络:
- [ ] 至少 3 个内部链接到相关文章
- [ ] 文章被列在某个概览页中
- [ ] 相关文章都反向链接到这篇

发布后:
- [ ] 本地预览检查
- [ ] 确认网站上看起来正常
```
